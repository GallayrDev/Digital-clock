# Digital Clock

A modern LED-style digital clock built using HTML, CSS, and JavaScript.

## Features

* Real-time digital clock
* 12-hour format with AM / PM
* Current weekday display
* Current date and month
* Live temperature using geolocation and weather API
* Responsive design for mobile devices
* LED-style UI with glowing effects

## Technologies Used

* HTML5
* CSS3
* JavaScript
* OpenWeather API

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/digital-clock.git
```

Open the project folder:

```bash
cd digital-clock
```

Run with Live Server in VS Code.

## API Setup

This project uses the OpenWeather API.

Get your free API key from:

https://openweathermap.org/api

Replace:

```js
appid=YOUR_API_KEY
```

with your own API key.
